What this application does

Maintenance is usually reactive (repair after a breakdown) or scheduled at fixed intervals regardless of machine condition. This project looks at a machine's current sensor readings and estimates the probability that it is in a failing state, so maintenance can be planned before a breakdown.

Readings are entered by hand or uploaded as a CSV. This is not live monitoring: nothing is read from machines automatically.

  1. Analyze a machine: readings go through the trained pipeline (feature engineering, scaling, model, probability calibration).
  2. The failure probability becomes a status (Normal, Warning or Critical), a health score and a recommended action.
  3. Warning and Critical results open one alert per machine. Later readings update it; a Normal reading resolves it. Everything is kept in the history.

Limitations

  • The AI4I 2020 dataset is synthetic and its failure modes follow fixed rules. Scores here are likely much higher than real machines would give, and nothing here has been validated on external or real industrial data.
  • Records are independent snapshots with no time order. The system judges whether current readings look like a failing state. The failure probability is not remaining useful life or time to failure.
  • Inputs are entered manually or uploaded. This is not live or real-time monitoring.
  • The test set has only {{ m.dataset.test_failures if m else 68 }} failures, so differences between close models are not statistically meaningful.
  • The overall model estimates failure risk, not failure type. The failure-mode table combines separate per-mode classifiers (only where reliable) with rule checks, and both are suggestions to investigate, not diagnoses. Random failures (RNF) cannot be identified.
  • The health score is a re-expression of the probability. It is not an independently validated measure of machine health.
  • "What-if" analysis shows how the model responds to a changed reading. It does not establish cause and effect.
  • Readings that combine values the training data never contained (for example high speed with high torque) may be predicted unreliably even when each value is in range.
