File format

The first row must be a header with these columns (any order):

machine_id, type, air_temp, process_temp, rpm, torque, tool_wear

  • Units: temperatures in kelvin, speed in rpm, torque in Nm, tool wear in minutes.

  • A machine keeps one type. A row whose type differs from the machine's is rejected.
